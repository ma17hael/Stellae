# Stellae

Stellae est l'écosystème logiciel des Automates de Malthael.

## Applications

- L'Intendant — Concordium Stellae
- Le Maître des Épreuves — Ludicrum Stellae
- L'Archiviste — Archivum Stellae
- Le Conservateur — Artificium Stellae
- Stellae Core

## Architecture

Stellae utilise un monorepo TypeScript basé sur pnpm.

```text
Discord Automates
        |
        v
    Stellae Core
        |
        v
    PostgreSQL
```

Ludicrum Stellae peut également communiquer avec Frosthold pour la gestion des serveurs de jeu.
